# VRX / ArduRover 4.4.0 / Nav2 验证报告

日期：2026-10-29。环境：本机 Ubuntu 22.04.5、ROS 2 Humble、Gazebo Garden 7.9、RTX 4090 无窗口渲染。

已完成独立仿真环境、固定版本飞控、导航闭环和测试设施的落地。控制链为 **Nav2 → rover_bridge → MAVROS → ArduRover SITL → VRX WAM-V 推进器**；导航定位来自飞控 EKF，Gazebo 真值只用于传感器生成和独立评估。原有硬件工程和 VRX 实验未被覆盖。

本轮对象是约 **5.37 m × 2.54 m** 碰撞包络的现成 WAM-V，不是最终 1.2 m × 0.7 m 实船。结果只能说明当前软件链路及该模型、这些场景下的表现。

最终导航参数下，单目标 **3/3**、多途经点 **3/3** 通过；单目标最大位置 / 航向误差为 **0.368 m / 0.047 rad**，多途经点终点最大误差为 **0.348 m / 0.161 rad**。静态绕障最小真值净空 **3.35 m**，动态障碍首次通过轮次最小净空 **2.24 m**，可视化补录轮次 **1.85 m**，均无接触。取消、两类不可达目标、所测风浪组合及 GPS_INPUT 固定解到点均通过。

需要保留的结论是：直接 Gazebo 时间重置尚不能自动恢复；定位质量门控、定位恢复后的自动续航和到点持续定点保持均未新增。不能把这些项目归为已通过。

正常到点和取消后的十秒窗口内，**双侧模型推力没有持续严格归零**：末尾为 −0.6 / +0.6 N，对应飞控 1499 / 1501 PWM；飞控仍解锁并处于 GUIDED。这是本轮明确测得的行为，不能用零速度指令或船速已经很小来替代“推进器停机”的结论。

## 配置与评估方法

WAM-V 左右推进器由 SERVO1 / SERVO3、功能 73 / 74 驱动，PWM 1000 / 1500 / 2000 映射为 −300 / 0 / +300 N。转角固定。正常控制、单侧 motor test 和双侧 RC 实验均经过飞控；只有无效协议的隔离测试发送负向夹具，且不发送有效非零推进命令。

推力观测有明确来源：早期记录为 ArduPilot 插件发给推进器的牛顿力命令，标记为 `command_topic_only`。后期添加物理推进器 `/thrust/ang_vel` 反馈，按实际 SDF 的 `ρ × K × D⁴ × |ω| × ω` 还原该模型的作用力，标记为 `thruster_feedback`，另保留输入命令。当前采用 `ForceCmd`、`velocity_control=true`；该反馈与 `AddWorldWrench` 使用同一物理更新内的力值，未模拟实际电机响应滞后，也不是独立测力传感器。依据为 [Gazebo 7.9 Thruster 实现](https://github.com/gazebosim/gz-sim/blob/gz-sim7_7.9.0/src/systems/thruster/Thruster.cc)。最终停车与故障补测使用此反馈，既有导航轨迹不因新增观测话题而改变。

世界及地图为 ENU。专用 SITL IMU 在船体参考点提供 FRD 数据，外部物理接口完成 ENU/NED 配准。MAVROS 使用飞控局部 `odom`；`map_origin` 从 **飞控上报的 GPS_GLOBAL_ORIGIN** 计算 `map → odom` 水平偏移，`odom_tf` 发布 `odom → base_stabilized → base_link`。地理配准节点不订阅真值，也不重设飞控原点。

16 线、720 水平采样、10 Hz LiDAR 经船体过滤、姿态变换和高度投影生成 `/scan`。源时间戳保留。只有原始水平射线确实观测到无回波时才保留 +Inf；没有有效观测的方向保留 NaN。全 NaN、旧扫描和缺少 TF 的扫描不能使桥保持运动许可。

| 最终 WAM-V 导航参数 | 值 |
|---|---:|
| 前向 / 角速度命令上限 | 0.3 m/s / 0.4 rad/s |
| 飞控加速 / 减速上限 | 0.2 m/s² / 0.2 m/s² |
| footprint padding | 0.5 m |
| 膨胀半径 / 衰减系数 | 4.5 m / 1.0 |
| DWB 障碍轮廓评分权重 | 1.0 |
| 局部栅格 / 预测时域 | 0.05 m / 3 s |
| 轨迹生成器 | StandardTrajectoryGenerator |
| 内部位置 / 航向到点容差 | 0.4 m / 0.2 rad |
| 独立真值验收阈值 | **0.5 m / 0.25 rad** |

初始参数为 0.4 m/s、padding 0.2 m、膨胀 3 m、障碍评分 0.02。移动障碍试验发生过实际接触，取消后也观测到约 0.86 m 的惯性位移，因此降低速度并增加几何与评分裕量。真实到点标准没有放宽。最终重复测试使用独立冷启动世界。

平面净空按包含推进器的碰撞轮廓凸包和实际障碍位置计算，另监听 Gazebo 接触。故意重叠的独立阳性对照产生 742 条接触消息，证明碰撞检测链确实工作。动态夹具是每 0.5 仿真秒更新位置的 2 m 方形刚体，速度 0.14 m/s；不代表完整的交通参与者模型。

## 导航结果

逐次到点误差、航向、净空和 10 秒漂移见 [最新导航测量表](results_summary.md)。[机器可读结果](results.json) 同时保存所有批测历史和最新结果，包含路径、参数与证据校验值。动作成功不足以通过：测试还检查真值阈值、途经点、碰撞、净空和零指令延迟。

单目标为 `(5, 0, 0)`；多途经点为 `(3, −3, −0.6)`、`(6, −4, 0)`；静态绕障目标为 `(18, 0, 0)`，已知障碍中心在 `(10, 0)`；动态目标为 `(12, 8, 0)`，障碍在第 3 秒出现、第 28 秒移开。不可达测试分别使用地图外目标和静态障碍内部目标。

风测试使用 3 m/s、方向 240°、种子 10、随机增益 0。波浪使用 gain 0.3、周期 5 s；gain 不是实测波高。比较使用相同几何地图和目标，记录实际船体起伏、姿态和 EKF 误差。

## 输入中断与进程故障

桥的预算针对**输出零速度指令**：command / odom / scan 为 0.6 s，state 为 2.1 s。它不是物理停车时限。输入测试在正常旋转后分别停止或破坏一个输入；物理仿真和飞控持续运行。

| 输入故障 | 零速度输出延迟（s） | 预算（s） | 判定 |
|---|---:|---:|---|
| command | 0.485 | 0.6 | 通过 |
| odom | 0.540 | 0.6 | 通过 |
| scan | 0.467 | 0.6 | 通过 |
| state | 1.285 | 2.1 | 通过 |
| all_nan | 0.129 | 0.6 | 通过 |
| stale_scan | 0.050 | 0.6 | 通过 |
| tf_missing | 0.073 | 0.6 | 通过 |

这些输入故障在约 0.15 rad/s 转向时注入。发零后继续观察约两秒，推进器反馈仍可能为左右相反的 1.8–2.4 N；该短窗口内没有观测到双侧力严格归零，state 中断窗口内也尚未同时达到运动阈值。以上“通过”仅指桥的发零预算，不代表物理停车预算通过。各次实际速度、推力、观察时长和位移保存在 `fault_inputs_result.json`。

| 情形 / 初始运动 | 模型推力归零（s） | 运动低于阈值（s） | 观察期净位移（m） |
|---|---:|---:|---:|
| 正常到点 | 十秒内未持续归零 | 3.125 | 0.205 |
| 取消航行 | 十秒内未持续归零 | 5.241 | 0.575 |
| 桥退出 / 转向约 0.15 rad/s | 6.409 | 5.301 | 0.062 |
| MAVROS 退出 / 前进约 0.24 m/s | 4.203 | 7.629 | 1.088 |
| SITL 退出 / 前进约 0.24 m/s | 0.087 | 5.932 | 0.545 |
| disarm / 前进约 0.24 m/s | 0.081 | 5.925 | 0.529 |

阈值为平面速度 < 0.02 m/s 且 |角速度| < 0.02 rad/s。到点/取消要求连续保持至少 0.5 s；进程故障和 disarm 记录首次达到阈值的采样。初始运动、观察时长和计时起点不同，不宜直接把这些行作性能排名。桥退出观察十秒，MAVROS/SITL 退出观察十二秒，disarm 观察八秒；物理仿真均持续推进，末尾模型推力为零。到点/取消的时间从 post-goal 首个记录样本起算，约有一个 0.1 s 采样周期的不确定性。

推进器反馈补测的九项单侧/双侧、正反向/中位检查全部通过。单侧 1600 / 1400 PWM 对应 ±60 N，双侧 RC override 1600 / 1400 经飞控映射为各 ±54 N。中位时双侧模型推力确为零，但反向运行后的第三秒仍有约 −0.11 m/s 船速。四项无效协议检查也全部通过，物理仿真继续推进、模型推力为零。

零指令后，GUIDED 控制器可能暂时保留小幅差动推力，船体也会继续运动。正常到点后的十秒观测期间没有持续定点保持策略；`metrics.post_goal` 单独记录持续至少 0.5 s 的推力全零和速度 / 角速度均低于 0.02 的延迟。`null` 表示窗口内未观测到该条件。进程退出测试则报告首次达到阈值的采样时刻及最终推力，采样约 10 Hz。

到点后观察窗口为十个墙钟秒，并记录同期仿真时间；后续显式 HOLD/disarm 的清理动作不计入停止测量。查看推力延迟时须同时查看 `thrust_measurement`，避免把早期命令观测误读成物理插件反馈。截图和视频为低帧率观察素材，时间测量以 JSONL 为准。

MAVROS 源系统号设为 255，与 `SYSID_MYGCS=255` 对齐，`FS_ACTION=2` 为 HOLD。此前默认源系统号 1 导致 RC override 被忽略，且地面站心跳未计入对应保护。修正后单独退出 MAVROS，飞控与物理继续运行并进入 HOLD；退出桥时 MAVROS 心跳仍继续，观测的是 GUIDED 指令超时行为。SITL 退出的实验使用非锁步物理，不能以冻结来冒充停车。

## GNSS 降级

使用目标固件支持的 `GPS_TYPE=14` 和 10 Hz `GPS_INPUT`，关闭第二 GPS；种子 42。独立配置 fix_type、报告精度、噪声、延迟和停发。这里测试的是现有行为，**没有新增 RTK/EKF 质量门控或自动恢复策略**。

|---|---:|---|---:|---|---|
| Fixed | 6 | 0.02 / 0.02 | 0.1 | 0.023 / 0.033 | 73 / 80 |
| Float | 5 | 0.30 / 0.30 | 0.1 | 0.108 / 0.203 | 120 / 120 |
| 普通 3D | 3 | 1.50 / 1.50 | 0.3 | 0.229 / 0.477 | 150 / 150 |
| 失锁但继续发包 | 1 | 1.50 / 1.50 | 0.1 | 1.579 / 2.476 | 77 / 120 |
| 停止 GPS 输入 | 1 | 1.50 / 1.50 | 0.3 | 2.584 / 2.605 | 0 / 150 |
| 恢复 Fixed | 6 | 0.02 / 0.02 | 0.1 | 0.324 / 2.605 | 0 / 199 |

该降级任务未完成：测试结束前 action 仍运行，离目标 **10.75 m**，随后由测试器取消，无碰撞。统计包含状态切换和恢复暂态，恢复行的最大值不代表重新收敛后的稳态误差。每个配置独立记录状态、σ、精度和延迟；此组试验同时改变多个量，不能将误差变化仅归因于 fix_type。

随后保持同一次物理/飞控进程运行到 **70,000 帧**，跨过 65,535，无新增控制器复位；结束时 odom 年龄 **0.061 s**、scan 年龄 **0.104 s**，长期协议检查通过。[完整 GNSS 与持续运行记录](../runs/20261029_061503_gnss/gnss_result.json)。

Float、普通定位及失锁初期仍可能产生导航指令，因为桥检查连接、模式、解锁和数据新鲜度，不依据 RTK 状态判停。持续失锁会触发本次飞控的原生 EKF 保护并转入 HOLD；恢复定位后 EKF 可重新收敛，但本次任务不会自动恢复 GUIDED。不能把“仍有新鲜 odom”视为“仍有可靠定位”，也不能把原生保护延迟视为桥主动的定位质量保护。

## 失败记录与边界

- **直接 Gazebo `reset all` 未通过自动恢复。** 世界时间归零后，MAVROS/TF/扫描链仍有未来时间戳；12 秒后 odom 与 scan 的年龄约为 −11.57 / −11.53 s。该次诊断在未解锁状态进行，桥保持零输出，但链路未自动恢复；它不构成带动力重置的验证。已验证的复位方式是停止并重新启动整个会话，见运行说明。
- **任务结束不等于停机。** `feedback_goal` 和最终 `cancel` 的零速度预览均为零，物理推进器反馈仍为约 ±0.6 N，飞控 servo 遥测与之相符，不能归因于 Gazebo 缓存了一个与飞控不一致的旧命令。本轮没有加入到点自动 disarm/HOLD 策略，也没有凭假定的电调死区把小推力裁成零；实船推进器死区和任务结束策略需后续明确。
- 初始 DWB LimitedAccelGenerator 与栅格评分使毫米每秒轨迹占优，船体停滞；局部 0.05 m 栅格、速度噪声死区和 StandardTrajectoryGenerator 解决该触发条件。曾试验的 6 s 时域导致近障没有有效轨迹，未保留为最终配置。
- 初始航向内部容差 0.25 rad 曾出现真值误差 0.263 rad，后收紧至 0.2 rad。风中初始化使 EKF 原点偏移约 0.52 m，新增飞控地理原点配准后再测。
- 移动障碍原始配置分别出现 1,896 和 475 条接触消息。第二次试验中，点云和 costmap 在接触前均记录了障碍，因此该失败不能归因于完全未观测到障碍。后续调整与回归保留这些失败。墙钟驱动的早期试验和最终仿真时钟驱动的夹具在记录中分别标注。
- 900/2100 PWM 的早期 motor test 设计错误：4.4.0 SITL 将通道 0/2 限制到 1000–2000，不能据此检验插件接收越界数据。后续改成隔离的无效协议夹具，原错误记录仍保留。
- 尚未验证最终实船尺寸、水动力、推进器曲线、真实定位延迟、真实 LiDAR 噪声，以及低矮、半潜或水下障碍。当前投影高度范围 0.25–3 m，测试障碍高度 3 m，不应推广到所有水面障碍。
- 风浪只覆盖列出的有限模型参数和固定种子；动态障碍只覆盖给定轨迹。未实现 COLREGS、任意障碍速度预测或持续定点保持。没有进行实船验证。
